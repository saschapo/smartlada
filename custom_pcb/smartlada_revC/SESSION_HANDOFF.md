## Что это
Продуктовая плата контроллера ламп фонаря ВАЗ. Ветка от revB (интегр. ESP32-C6-WROOM-1),
минус дисплей-на-плате, плюс механика под установку в фонарь. **Схема ГОТОВА, PCB РАЗВЕДЕНА.**

## Архитектура (финал)
- **MCU:** ESP32-C6-WROOM-1-N16 (модуль, закуплен, 5 шт).
- **Питание: USB-C PD, профиль 12В/3А** через **CH224K** (ESSOP-10, 12В-триггер). Лампы 12В
  НАПРЯМУЮ (без понижайки). Рекоменд. БП COMMO Core 45-140Вт (в инструкцию: «в один порт»,
  у 45Вт при двух портах 12В падает до 1.67А).
- **CH224K обвязка:** CFG1=24k→GND (=12В), CFG2/3=NC, **DP/DM отвязаны от D+/D- и закорочены
  между собой** (чистый PD, QC не используем), VBUS(8) через R21-последоват., VDD(1) через
  R19 1k + 1uF. **PG — open-drain, active-LOW.**
- **Детект «зарядка vs компьютер»:** firmware включает каналы только при **«PG=LOW И нет
  USB-хоста»** (защита от 30Вт из ноутбука). Дефолт каналов OFF.
- **VBUS-sense:** делитель 100k/33k → ADC ESP.
- **Buck:** TPS54202 12→3.3В. FB-делитель = **R4/R5** (стоит вплотную к U2, ~4.5мм ✓).
  EN плавающий (наследие revB, работает через внутр. pull-up).
- **4 канала ламп:** AOD4184A (DPAK), low-side, gate 100R + pulldown 100k на PGND.
  **Нагрузка 2×10Вт + 2×5Вт = 30Вт** (под бюджет PD).
- **ESD:** USBLC6-2SC6 на D+/D-. **VBUS-пин U4 → +3V3, НЕ 12В** (5-вольтовая деталь!).
- **Индикация:** 6× красных LED 0805 (4 канала + 12В + 3.3В).
- **Выходы ламп:** Faston 6.3мм «папа» TE 63951-1 (футпринт `TE_1217754-1`), ×5 (4 OUT + 1
  общий +12В). «Мама» под обжим на провода — заказать.
- **Дисплей:** SSD1315 + 4 кнопки, вынос кабелем → **J4** (I2C + KEY1-4 + 3V3/GND, 8-pin,
  угловой pin header; кабель BLS-8 Platan 10660).
- **UART debug:** J8 (TX/RX/GND).
- **C_bulk 470мкФ/25В** на 12В rail. **Тест-точки** GND/12V/3V3/PG.
- **Убрано:** барел, предохранитель, TVS, переполюсовка (Q5), выключатель — защита входа
  делегирована PD-источнику. RGB, датчики — тоже убраны.

## Механика
- Плата **100×59 мм**, 4× крепёжных Ø3.2 (клиренс M3), прямоугольник **88×47**, NPTH.
- Зазор над крепёжной пластиной 2мм (back-side пропай/via). Faston и антенна WROOM торчат
  за край (намеренно, out-of-bounds warnings исключены).

## PCB статус
- **2 слоя** (F.Cu сигналы + B.Cu GND-полигон). Саша перешёл с 4 на 2 слоя.
  (Моя рекомендация была 4 ради RF/buck; на 2 работает, если земля под D+/D-/buck/антенной
  сплошная.)
- **DRC чистый, КРОМЕ 66× `footprint_symbol_field_mismatch` (поле Platan)** — это ШУМ от
  впаянного поля Platan (символы имеют, футпринты нет). **Фикс:** Update PCB from Schematic
  с галкой **«Update footprint fields from symbols»**, ИЛИ Board Setup → Violation Severity →
  `footprint_symbol_field_mismatch` = Ignore.
- GND-разрывы (намеренные, короткие): +12В для LED в зоне ламп (там B-полигон убран),
  CC1/CC2 по B, +3V3 на U4 и на J4. **B.Cu GND под лампами убран** (не пускать шум в землю).
- USB D+/D-: длины ~43.8мм согласованы (для FS не обязательно). ПРОВЕРИТЬ: сплошная B.Cu
  земля под парой (нет щелей поперёк).
- **PGND↔GND: звезда через NT1** (SMD net-tie). D6 (индик. LED) переведён на GND (был PGND).

## Нумерация R/C — ПЕРЕНУМЕРОВАНА Сашей (инкрементально по блокам)
НЕ использовать старую карту. Buck FB = R4/R5. VBUS-делитель = R7(100k)/R8(33k). Проверять
по актуальному нетлисту.

## Переименование
**LAMP0..3 → OUT0..3** (Саша, для читаемости шелкографии).

## Firmware pin-map — ИЗМЕНЁН при разводке (перепроверить в схеме!)
- **CH2 ↔ CH3 поменяны** (U1 пины 26/27, IO2/IO3). Финальную карту OUT↔IO сверить в схеме.
- **CH224_PG → IO10** (было IO5).
- **VBUS-sense ADC → IO4.**
- **USB D+/D- → IO13/IO12** (native USB).
- **I2C → IO18/IO19; KEY1-4 → IO20-23; UART TX/RX → GPIO16/17** (J8 пины 2/3 переставлены —
  сверить silk TX/RX с нетами!).
- **BOOT → IO9; RESET → EN.**
- База revB-remap: IO0=CH1(OUT1), IO1=CH0(OUT0). После свопа CH2/CH3 — сверить.
