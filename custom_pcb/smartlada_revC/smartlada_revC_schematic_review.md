# SmartLada Rev C — проверка схемы и финальный список правок

Проверено: 2026-08-13 (перепроверка по актуальному нетлисту `smartlada_revC.kicad_sch`).
Метод: экспорт нетлиста/футпринтов kicad-cli + сверка с даташитом CH224K и спекой/BOM.

**Статус: ERC 0/0. До PCB закрыть P0 (3 правки: DP/DM, USBLC6, C_bulk + косметика). P1 — до финализации.**

## ✅ Уже корректно (проверено по нетлисту)

- **PG и VBUS-измерение РАЗДЕЛЕНЫ** (это был спорный пункт прежнего ревью — уже сделано):
  - `PG_SENS`: U3.10 (PG) → ESP **IO5**, подтяжка **R22 10k → +3V3**.
  - VBUS-делитель: `+12V → R16 100k → IO4 → R17 33k → GND` (ADC1_CH4). Отдельная сеть.
- **GND ESP — все 11 пинов** (1, 28, 29_1..29_9) на GND. ✓
- **Buck FB** R2 100k / R3 22k → 3.30 В. ✓
- **CFG1 = 24k → GND** (=12 В), **CFG2/CFG3 = NC** — по даташиту CH224K. ✓
- **VDD/VBUS CH224K** — по эталону (раздел 6.1): VDD(1) через R19 1k + C11 1uF; VBUS(8) через
  R21 10k (даташит требует последовательный резистор к обоим). ✓
- **USB D+/D-**: IO13=D+, IO12=D-, A/B-стороны разъёма сшиты (реверсивность). ✓
- **Каналы**: CH0..3_IN → Rg 100R → Q1..4 (AOD4184A) → LAMP0..3; Rpd 100k на PGND. ✓
- **LED**: 6 шт (D2-D7) — 4 канала + 12В (D7) + 3.3В (D6); 5×4k7 + 1×1k. ✓
- **Все футпринты R/C/LED — 0805/1210 hand-solder** (в т.ч. **C5 уже 0805** — исправлено). ✓
- **Faston** J2/J3/J5/J6/J7 (LAMP0-3 + 12V), **CFG/CC/GND** — ок.
- **J1 SBU1/SBU2 = NC** (флаги стоят, ERC чист). ✓
- **U1 полностью N16**: value, MP (партномер), footprint `XCVR_...N16`, 3D `...N16.step` —
  все N8-ссылки убраны. ✓

## P0 — исправить до PCB

### 1. DP/DM CH224K: отвязать от D+/D- и закоротить между собой  ⟵ по даташиту
- [ ] Убрать провод от **U3.DP(4)** и **U3.DM(5)** к `USB_D+`/`USB_D-`.
- [ ] **Закоротить U3.4 ↔ U3.5 между собой** (изолированная терминация DP/DM).
- [ ] **VBUS(8) НЕ трогать** — остаётся через R21. («VBUS можно NC» — это раздел 6.3 male/E-Mark,
  а у нас 6.1 female-порт + резисторная конфигурация.)
- [ ] После этого `USB_D+/-` = только разъём J1 ↔ USBLC6 ↔ ESP.

Почему: даташит — при отказе от QC-протоколов (наш чистый PD) DP/DM CH224K отвязывают от
Type-C; для PD-only даташит показывает DP↔DM **закороченными на стороне чипа**. Иначе CH224K
дёргает пару под детект и мешает USB-данным ESP. Не 0Ω-джамперы — просто отвязать + шорт.

### 2. Добавить ESD USBLC6 (U4)
- [ ] Поставить **U4 USBLC6-2SC6** (SOT-23-6) у J1, на линии `USB_D+/-`.
- [ ] **⚠️ VBUS/опорный пин U4 — на `+3V3`, НЕ на шину 12В.** USBLC6 — 5-вольтовая деталь;
  её клампинг-пин при 12 В сгорит. Через неё идут только D+/D- (домен 3.3 В).
- [ ] GND U4 — на сплошную землю кратчайшим путём.
- [ ] На PCB: U4 ближе к разъёму, чем ESP/CH224K.

Почему: заявлен в спеке/BOM, на схеме отсутствует.

### 3. Добавить bulk-конденсатор шины +12 В
- [ ] `C_bulk` **470 µF / 25 В** SMD электролит (BOM: EEEFK1E471P, Platan 696157719) между
  `+12V` и GND.
- [ ] На PCB — у входа/ветвления к лампам, короткий токовый контур.

Почему: часть плана проверки пускового тока ламп (§2.2). C3/C4 10µF его не заменяют.

### 4. (косметика) Переименовать сеть PG
- [ ] `PG_SENS` → `CH224_PG` — чтобы имя не намекало на аналоговое напряжение.

(SBU1/2 NC и U1→N16 — **уже сделано**, см. «уже корректно».)

## P1 — добавить до финализации схемы

### 6. UART debug header
- [ ] `J_UART` 1×3, 2.54: **GND / TXD0 (GPIO16) / RXD0 (GPIO17)**.
- [ ] Шелкография порядка: `GND | TX(board) | RX(board)`.
- [ ] Убедиться, что `UART_TX/RX` не остались только метками без разъёма.

### 7. Тест-точки
- [ ] `TP_GND`, `TP_12V`, `TP_3V3` (требует спека).
- [ ] Рекомендуется `TP_PG`, `TP_VBUS_SENSE` — почти бесплатно, сильно упрощают отладку PD/прошивки.

## После сборки (валидация на железе, до тиража)

- [ ] **PD-сценарий:** COMMO 12В/3А → CH224K запрашивает 12 В (PG=LOW, VBUS-ADC≈12В), ESP
  стартует, каналы включаются, USB-линии не мешают PD.
- [ ] **PC-сценарий:** плата держится на 5 В, ESP стабильно перечисляется и шьётся по
  USB Serial/JTAG, лампы OFF (детект хоста).
- [ ] Проверить **оба положения** штекера USB-C.
- [ ] Пусковой ток ламп: держит ли PD (§2.2), нужен ли firmware soft-start/стаггер.

---

## Firmware-заметки (следствия схемы)

- **PG active-LOW**: «12 В согласовано» = `CH224_PG == 0`. Напряжение — отдельно по ADC (IO4).
- **Гейт каналов**: включать только при `PG==0` **И** нет USB-хоста (§2.3); дефолт OFF.
- **Маппинг каналов** (revB-remap): IO0=CH1, IO1=CH0, IO2=CH3, IO3=CH2.
- **VBUS-ADC** (IO4): делитель 100k/33k → при 12 В ≈ 2.98 В; использовать для контроля rail и
  теста инраша.

## Финальный чек-лист перед PCB

- [ ] P0 (1-5) закрыты, повторный **ERC 0/0**.
- [ ] Футпринты всех R/C/LED — 0805+ hand-solder (проверено: да; следить при добавлении U4/C_bulk/J_UART).
- [ ] C3/C4 — рабочее напряжение **≥25 В** (подтвердить у выбранного 10µF 1210).
- [ ] U3: CFG1=24k→GND, CFG2/3=NC; DP/DM отвязаны от D+/D- и закорочены DP↔DM; VBUS через R21; PG-подтяжка к 3V3 отдельно от ADC.
- [ ] U4 ESD у J1, VBUS-пин на +3V3; D+/D- как пара с непрерывной землёй под ними.
- [ ] RF keepout под антенной WROOM — по даташиту модуля.
- [ ] C_bulk и силовые дорожки под ток ламп (2.5 А): широкие +12V и GND-return.
- [ ] Faston: посадка **TE_1217754-1** совпадает с заказываемым **63951-1** (Ø/шаг выводов),
  не только лезвие.
- [ ] Номера пинов разъёмов = шелкография = реальный кабель дисплея (BLS-8).
- [ ] Габарит 100×59, отверстия Ø3.2 @ 88×47, зазор 2 мм над пластиной (back-side пропай).
