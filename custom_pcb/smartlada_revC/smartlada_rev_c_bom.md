# SmartLada Rev C — BOM (в работе)

Проверка по Платану (`www.platan.ru` API). Правило: пассивы **0805 `*_HandSolder`**, ИС/разъёмы
паяемые вручную. Цены/наличие — на 2026-08-13, меняются. **QUANTY 0 + POSTAV «N дней» = на
главном складе 0, привоз за N дней** (не «нет в наличии»). **Следи за MINZAKAZ (MOQ)** — у части
позиций катушка.

Статус схемы: ядро нарисовано; **не добавлены**: USB-C+CH224K вход, VBUS-делитель, 6× LED,
UART-хедер. Их строки помечены `[добавить в схему]`.
