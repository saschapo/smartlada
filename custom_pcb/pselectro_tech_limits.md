# ЭЛЕКТРОконнект / pselectro.ru — технологические возможности (справочник)

Извлечено из `datasheets/electroconnect_tech_limits.pdf` (стр. «Технологические
возможности изготовления печатных плат», ООО «ЭЛЕКТРОконнект», Новосибирск,
order@pselectro.ru). Приёмка по IPC-A-600, ГОСТ Р 53429-2009, ГОСТ 23752-79.

Две колонки: **Стандарт** (штатный техпроцесс, без наценки/согласования) и
**Предел** (абсолютная возможность, обычно дороже/по согласованию/выше отбраковка).
**Проектируем по «Стандарту».** Буквы (A, B, C…) — обозначения на чертеже завода.

**Важно для нас:**
- **Чёрная (цветная) маска:** переходные отверстия **⌀ ≤ 0.4 мм рекомендуется закрывать
  маской (tenting)**. У нас маска чёрная и via 0.3 → тентим (в KiCad tenting front/back = yes).
- Наши via 0.6/0.3 давали поясок 0.15 = **предел**, не стандарт. Под «Стандарт» нужен поясок
  **0.20** → via **0.7/0.3** (или силовые 0.8/0.4 = 0.20).
- Контур скрайбим → медь-край **0.5 мм** (совпало с текущей настройкой).

### Финиш и контроль
- Финиш: HASL (ПОС-63; **не тоньше 1 мм**), иммерсионное золото (ENIG), иммерсионное олово.
- Электроконтроль (flying probe): min площадка 0.2, min толщина 0.5.
- Контроль импеданса: допуск **±10%** (заказывается отдельно; мы не заказываем).
- Заполнение отверстий компаундом: ⌀ 0.2–0.6, min толщина платы 0.5.
