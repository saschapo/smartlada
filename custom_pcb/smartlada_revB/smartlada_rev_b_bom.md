# SmartLada Rev B — BOM (на 4 платы + запас)

Снято с разведённой платы (2026-07-25). Наличие/цены — Platan (shop.platan.ru), retail.
Модуль U1 — **AliExpress** (не Platan). NT1 — net-tie, физической детали нет.
Правило Platan: для позиций **со склада** (QUANTY>0) продают от 1 шт, MINZAKAZ в API — оптовый.

Поля для KiCad Symbol Fields Table: **MPN** (part number) и **MF** (manufacturer).

(нативный USB C6 работает при прямом соединении, series-R не нужен — datasheet/§6). Поэтому:
→ **просто запаять пятачки перемычкой/каплей** (детали не нужно), либо взять 0805 0Ω из
AliExpress-набора. Покупать катушку 0R на Platan не обязательно.

## Наличие Platan (снято 2026-07-29, retail)

**Со склада (от 1 шт):** 100nF TCC0603 (850), 22µF GRT21 (10907), WS2812B-V5 (1551),
USB-B USBB-1J-W (5267), PLS-40/J5 (14377), J4 гнездо DS1023-1x40S21 (333).

**Под заказ 1-2 раб.дня, MIN 1** (не склад, но берут от 1): 100k, 100R, 10k, 22k, 1µF,
10µF Murata (замена!), 100µF, AOD4185, TPS54202, USBLC6, дроссель L1, DG308/J2, держатель
фьюза, кнопки 1-1825910-0.

**Требуют внимания (большой MIN или долгий лид):**
- **Q1-4 AOD4184A** — 0 склад, **MIN 13**, 3-4 дня → берём 16.
- **J1 DG127** — 0 склад, **MIN 10**, 5 дней → берём 10.
- **Фьюз FS-52GT-4.0/250** — 0 склад, **лид 1-2 НЕДЕЛИ**, MIN 2 → заказать РАНЬШЕ остального.
- **10µF Hongda HLC1210 (старый) был MIN 1000** → заменён на Murata GRM32ER71H106KA12L (MIN 1).
- **10k/22k/0R** — решены ранее (10k/22k MIN 1; 0R R5/R6 = перемычка, не покупаем).
