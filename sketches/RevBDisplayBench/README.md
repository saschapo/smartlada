# RevBDisplayBench

Стенд для сравнения настроек обновления OLED (SmartLada Rev B). Несколько
пресетов «частота кадра панели (0xD5) + скорость шины I2C», живые метрики и
двигающийся квадрат для оценки плавности — по глазу и на камеру.

## Управление

| Кнопка | Действие |
|--------|----------|
| K1 (^) | следующий пресет (по кругу) |
| K2 (v) | режим заливки FULL ↔ PARTIAL |
| K3 (#) | скорость квадрата − |
| K4 (*) | скорость квадрата + |

Квадрат 15×15, движется влево-вправо бесконечно. Скорость 0…10: `0` — стоп,
`10` — полный цикл (туда-обратно) за 5 с.

## FULL vs PARTIAL (tearing)

У SSD1306/SSD1315 по I2C нет линии TE (frame-sync), поэтому настоящий vsync
невозможен: панель сканирует память на стекло асинхронно с нашей заливкой, и
движущийся квадрат «срезает» на 1–2 px (tearing). Рычаги — только уменьшать окно
заливки:

- **FULL** — заливается весь кадр (1 КБ, ~14–28 мс). Окно tearing большое.
- **PARTIAL** — заливаются только 2 страницы полосы квадрата в диапазоне столбцов
  старого+нового положения (~40 байт, <1 мс). Окно tearing схлопывается почти в
  ноль. В этом режиме экранная статистика замирает (обновляется по нажатию),
  живые `flush`/`fps` идут в Serial, чтобы не добавлять периодический полный
  перелив.

Сравнивай FULL/PARTIAL на камеру на одной скорости — разница по tearing должна
быть наглядной. Дополнительно 800k-пресеты (P3/P4) укорачивают окно и в FULL.

## Пресеты

| # | Имя | 0xD5 | I2C |
|---|-----|------|-----|
| 1 | DEFAULT | 0x80 | 400k |
| 2 | FASTCLK | 0xF0 (макс. частота кадра) | 400k |
| 3 | I2C 800 | 0x80 | 800k |
| 4 | MAXBOTH | 0xF0 | 800k |
| 5 | SLOWCLK | 0x00 (мин. частота кадра) | 400k |

На экране: индекс/имя пресета, `d5`, частота I2C, `flush` (время заливки кадра,
мкс) и `fps` (реальная частота перерисовки). Цикл перерисовывается максимально
быстро, поэтому `fps ~= 1 / flush`, и эффект скорости шины виден напрямую.

`0xD5`: старший ниблл — частота осциллятора (кадр панели), младший — делитель.
Выше частота → мельче/незаметнее полосы rolling shutter и меньше мерцание, ценой
чуть большего тока. `0x00` намеренно даёт низкую частоту кадра для сравнения.

## Сборка/заливка

```
arduino-cli compile --fqbn esp32:esp32:esp32c6:CDCOnBoot=cdc sketches/RevBDisplayBench
arduino-cli upload  --fqbn esp32:esp32:esp32c6:CDCOnBoot=cdc -p <PORT> sketches/RevBDisplayBench
```

Библиотеки: `Adafruit SSD1306`, `Adafruit GFX`.
